# Teamisty Documentation

This directory contains the approved project documentation used by the Teamisty implementation team.

| Document | What it defines |
| --- | --- |
| [Product Specification](PRODUCT_SPECIFICATION.md) | Project objective, scope, user roles, product rules, permissions, workflows, validation, and acceptance criteria. |
| [Technical Design](TECHNICAL_DESIGN.md) | Architecture, service boundaries, data ownership, API and event contracts, authentication, resilience, and observability. |
| [Implementation Guide](IMPLEMENTATION_GUIDE.md) | Technology stack, repository layout, build order, testing, CI/CD, deployment, and demonstration evidence. |

## Documentation rules

- Product behaviour is defined by `PRODUCT_SPECIFICATION.md`.
- Architecture and service contracts are defined by `TECHNICAL_DESIGN.md`.
- Delivery, infrastructure, and implementation workflow are defined by `IMPLEMENTATION_GUIDE.md`.
- Update the relevant document whenever an implementation decision changes its behaviour or technical design.

The decision log remains outside this repository for now, by project direction.
