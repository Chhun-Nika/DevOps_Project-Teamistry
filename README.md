# Teamisty

Teamisty is a task-management application built as a microservices project.

This repository structure is established before application configuration begins. The detailed project documentation will be reviewed locally and moved into `docs/` after approval.

## Repository layout

- `frontend/` — web application.
- `services/` — independently deployable backend services.
- `contracts/` — API and asynchronous event contracts shared between services.
- `infra/` — infrastructure configuration for local and deployed environments.
- `.github/workflows/` — CI/CD workflows.
- `docs/` — approved project documentation, added later.

Setup, run, test, and deployment instructions will be added after the working environment is configured.
